# ATM Interface

A console-based ATM Interface developed using Java and Object-Oriented Programming (OOP) concepts.

## 📌 Project Description

This project simulates basic ATM operations through a Java console application.

## 🚀 Features

- Account creation
- User login
- Balance checking
- Deposit money
- Withdraw money
- Bank account management
- Transaction handling

## 🛠️ Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Eclipse IDE
- Git
- GitHub
